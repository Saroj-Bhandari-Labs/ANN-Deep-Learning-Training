## Project Title

Parkinson's Disease Detection Using Artificial Neural Networks (ANN)

---

## Objective

The objective of this project is to build and evaluate a neural network
model capable of detecting the presence of Parkinson's disease from
biomedical voice measurements. Parkinson's disease is a progressive
neurological disorder that affects motor control, and early changes in
speech patterns (e.g., jitter, shimmer, frequency variation) have been
shown to correlate with the condition. This project explores whether a
feed-forward artificial neural network (ANN) can learn to distinguish
between healthy individuals and Parkinson's patients based on these voice
features, while addressing challenges such as a small dataset size and
class imbalance.

---

## Dataset

- **File:** `dataset/parkinsons.data`
- **Format:** CSV
- **Samples:** Voice recordings from individuals, each labeled as healthy
  or Parkinson's-positive.
- **Target column:** `status` (`0` = healthy, `1` = Parkinson's)
- **Dropped column:** `name` (non-predictive identifier)
- **Features:** 22 biomedical voice measurement attributes, including:
  - Fundamental frequency statistics (MDVP:Fo, MDVP:Fhi, MDVP:Flo)
  - Jitter measures (variation in frequency)
  - Shimmer measures (variation in amplitude)
  - Noise-to-harmonics and harmonics-to-noise ratios (NHR, HNR)
  - Nonlinear dynamical complexity measures (RPDE, D2, DFA)
  - Fundamental frequency variation measures (spread1, spread2, PPE)
- **Class balance:** The dataset is imbalanced, with a larger proportion
  of Parkinson's-positive samples than healthy samples.

---

## ANN Architecture

A feed-forward Sequential neural network was implemented using
TensorFlow/Keras:

| Layer | Units | Activation | Notes |
|---|---|---|---|
| Input | 22 (feature count) | — | Scaled input features |
| Dense | 32 | ReLU | Hidden layer 1 |
| BatchNormalization | — | — | Normalizes activations |
| Dropout | — | — | 20% dropout rate |
| Dense | 16 | ReLU | Hidden layer 2 |
| BatchNormalization | — | — | Normalizes activations |
| Dropout | — | — | 20% dropout rate |
| Dense | 1 | Sigmoid | Output: probability of Parkinson's |

**Training configuration:**

- **Optimizer:** Adam (learning rate = 0.001)
- **Loss function:** Binary cross-entropy
- **Metric:** Accuracy
- **Epochs:** Up to 150, with early stopping (patience = 15 on
  validation loss, best weights restored)
- **Batch size:** 16
- **Class weighting:** Balanced class weights applied to correct for
  class imbalance
- **Preprocessing:** Features standardized using `StandardScaler`
  (zero mean, unit variance), fit on training data only

## Conclusion

This project demonstrates a complete pipeline for Parkinson's disease
detection from voice measurements using an artificial neural network,
covering data preprocessing, class imbalance handling, model design, and
evaluation. Given the small size of the dataset, results should be
interpreted with caution, and comparison against simpler baseline models
(e.g., logistic regression, random forest) is recommended to confirm that
the added complexity of a neural network provides a meaningful
improvement. Future work could include cross-validation for more robust
performance estimates, hyperparameter tuning, and feature selection to
address collinearity among the jitter/shimmer measurements.
